# Siggy artwork source

Created with the built-in image-generation tool, using the previous Ciggy app icon as an identity reference. The selected transparent PNG is committed in the shared asset catalog and in both Icon Composer documents. Icon layout, background color, materials, and system appearance rendering are authored separately with Apple's Icon Composer.

## Final generation prompt

Use case: precise-object-edit / logo-brand

Asset type: transparent foreground artwork for a native Apple Icon Composer app icon, iPhone and Apple Watch.

Input image: existing Siggy mascot app icon, identity reference and edit target.

Primary request: professionally refine the SAME Siggy character into a polished, clean, distinctive icon mascot. Preserve the friendly cream cigarette body, warm orange filter, dark ink outline, two oval eyes, small confident smile, one subtle peach cheek, and charming slightly diagonal dancing stance. Correct the anatomy: exactly two arms and exactly two legs, each visibly and smoothly attached to the body with no gaps; rounded simple mitten-like hands and neat oval shoes. Make the body silhouette more balanced and the face centered and readable. A short, simple soft-cream smoke curl may rise from a small scalloped ash cap, fully within the central composition. Strong deliberate smooth curves and consistent bold dark espresso outline; the character should feel like refined vector brand artwork, not a sketch, not a 3D toy.

Scene/backdrop: genuinely transparent alpha background. Remove ALL original background: no purple circle, no peach gradient, no ring, no sparkles, no ground shadow. Output ONLY the isolated complete mascot.

Composition: square 1024 by 1024 canvas; entire character including smoke, hands and shoes contained within the central 76% of width and 82% of height, centered optically, with generous transparent margins for a circular Watch mask. Character large enough for eyes and smile to read at 60 px.

Color: warm ivory body, restrained coral-orange filter, dark espresso ink (not purple); flat clean fills with minimal illustration detail. Keep all interior cream regions fully opaque.

Constraints: no text, no border, no rounded-square or circular icon container, no icon mockup, no watermark, no decorative objects, no baked glass highlights or cast shadow. No disconnected limbs, no extra fingers, no missing outlines, no duplicated eyes. Treat all body details as one coherent finished mascot artwork. Apple Icon Composer will add the background and system materials separately.

## Output and native rendering

The tool returned a 1254 × 1254 transparent PNG. Icon Composer positions it at 72% scale with a -20-point horizontal offset, keeping the whole silhouette within the iOS and Watch masks. Its separate background uses solid apricot `#F0AD78`. The foreground uses native specular effects, no translucency, and a neutral shadow at 22%. Default, Dark, tinted, and watchOS previews are exported with Apple's bundled `ictool` for inspection.
