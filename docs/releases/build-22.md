# TestFlight 1.0 (22) — What to Test

Update Ciggy on both iPhone and Apple Watch. Log one cigarette on the Watch while the phone is out of reach. Reconnect the devices, open both apps, and check that the count increases once. Adjust a detection review on one device, then relaunch both apps and check that the correction persists.

Open the Watch app for a while, then return to the watch face. In Settings → Tracking details, check that background history checks resume when watchOS next grants time. The Watch now bounds every saved-motion query at the recorder. History older than Core Motion’s retention window can still be unavailable, and watchOS controls when checks run.

In the private dashboard, select a recording that spans the edge of a reporting period. Change the period or refresh a rolling period. An untouched activity label should follow the visible time range. A draft you have edited should retain your times. Save a label and reload to verify it persisted.
