# TestFlight 1.0 (21) — What to Test

Reviews on iPhone and Apple Watch now keep the broad review period and list each original cigarette estimate separately: motion-window start to the time it was counted. The list starts expanded and can be collapsed. Older estimates without complete timestamps say timing or start unavailable. Adjusting a count keeps the original evidence and does not invent times for added cigarettes.

On iPhone, tap “Inspect motion & report a miss” inside a review. The private motion dashboard opens inside Ciggy, with the review period and paired tester selected when available. Sign in through the existing private dashboard access; if no tester is selected, choose yours.

Zoom or drag across the graph, including empty sections, or enter exact local start/end times. Save how many cigarettes were missed, your observation and optional notes. Saved feedback stays private for 14 days. “Prepare evidence file”, then “Share or download evidence”, exports a JSON file with the feedback, available raw motion, coverage gaps, activity labels and last reported delivery status. Attach that file to Codex for investigation. Saving feedback does not change your total; use Adjust count separately.

Please update both apps. Check individual windows, earlier-day reviews, count corrections across relaunch, in-app sign-in and return to Ciggy. Test a miss with visible motion and one with no uploaded data; verify the selected tester, time range and exported file.

Missing uploads do not prove tracking was stopped: sharing settings, delayed delivery, retention and capture gaps can all leave no data. Calibration must have been enabled for raw motion to be available. Detection thresholds and watchOS scheduling limits are unchanged; feedback does not automatically train or fix the detector.
